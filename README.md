# Reflex // Market Move Radar — demo dashboard

OSINT-style intelligence radar for commercial teams, built as the demo
front-end for the Nestlé Vietnam AI Reinvention application
(use case SALES-2, Market Move Radar).

All signals on the page are SYNTHETIC DEMO DATA (labelled in the UI).
The engine it visualises — Reflex, a two-stage market-intelligence
agent (calibrated ML triage → LLM verification → human decision) —
is real and runs on live marketplace data in another market.

Open index.html, or see the live GitHub Pages deployment.
